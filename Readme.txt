              ✨ STERB TRANSLATOR ✨
==================================================

Welcome to Sterb Translator! A lightweight, AI-powered desktop translation tool.

---
🚀 QUICK START GUIDE
---

1. Launch "SterbTranslator.exe".
2. Press CTRL + M to open the Control Panel Dashboard.
3. You will need a FREE Groq API key to use the translator. Follow the steps below to get yours in 30 seconds.

---
🔑 HOW TO GET A FREE GROQ API KEY
---

1. Go to the official Groq Console website: 
   https://console.groq.com/
2. Sign up for a free account (you can use Google or GitHub to log in instantly).
3. Navigate to the "API Keys" section on the left sidebar.
4. Click "Create API Key", give it any name, and copy your generated key (it starts with "gsk_").

---
⚙️ HOW TO SET YOUR API KEY IN THE APP
---

1. Open the Sterb Translator Dashboard (CTRL + M).
2. Click the Gear icon (⚙) in the top-right corner of the window.
3. Paste your Groq API key into the input box and click "Save Key".
4. That's it! Your key is saved securely on your PC.

---
🎮 HOTKEYS & CONTROLS
---

* CTRL + B : Translate text based on your active mode:
  - Screen Region OCR: Drags a box over Japanese/English text on your screen to translate it.
  - Highlight & Copy: Instantly translates text you have currently highlighted on your screen.
* CTRL + M : Open or bring the Sterb Translator Dashboard to the front.
* Click the "✕" button in the top-right corner to close the dashboard (it will keep running quietly in the background).
